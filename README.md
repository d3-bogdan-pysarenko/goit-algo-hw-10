# Висновки дозавдання 2

Не зважаючи на те, що для функції, яка розглядається у завданні 2, метод `quad` є ефективнішим, **метод Монте-Карло** продемонстрував свою працездатність. Він є універсальним інструментом якому не важливо, наскільки складна формула функції — достатньо лише мати змогу перевірити, чи знаходиться точка "всередині" області чи "зовні".

**Метод Монте-Карло** є стохастичним (випадковим). Його точність безпосередньо залежить від кількості генерованих точок (__N__):
- Похибка методу зменшується пропорційно до `1` / `√N`.
- Щоб зробити розрахунок у **10** разів точнішим, нам потрібно збільшити кількість точок у **100** разів.
- У конкретно цьому випадку абсолютна похибка при **100,000** точок склала приблизно *0.01 – 0.02* (що становить менше **1%**), що є достатнім для багатьох прикладних задач, але поступається точності методу `quad`.
